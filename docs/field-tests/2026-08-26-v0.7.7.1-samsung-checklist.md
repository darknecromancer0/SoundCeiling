# SoundCeiling v0.7.7.1 Samsung Session DSP checklist

Target: Samsung SM-A528B / Android 14. Keep the user's normal low-volume anchor; **3/15 is a required acceptance point**. The previously granted `android.permission.DUMP` should remain granted when installing this build as an update with the same package/signing identity.

## 1. Neutral attach must be genuinely neutral

1. Start Yandex Music or YouTube with Smart PCM and Global DSP enabled.
2. Set Samsung Media to 3/15 and do not move it during the first probe.
3. Let stable playback run for at least 30 seconds.

Pass:
- an exact non-zero session is discovered and bound;
- the Enhanced Session candidate uses the input-gain-only topology;
- `session_dsp_attach_result ... safe=true ... reason=attach_neutral_safe` may advance to the bounded probe;
- there is no audible large step merely from the 0 dB attach;
- Samsung Media remains 3/15.

Fail-closed:
- a stable finite non-neutral attach still produces `session_neutral_attach_unsafe` and suppresses that session;
- no unverified transport may receive ordinary positive normalization gain.

## 2. Unstable meter evidence is inconclusive, not unsafe

Dynamic music can make asynchronous PCM/Visualizer residuals noisy.

Pass:
- unstable evidence reports `attach_unstable_residuals` / `session_dsp_attach_inconclusive` or `session_dsp_probe_inconclusive`;
- inconclusive evidence releases the candidate and retries later after cooldown;
- it does **not** produce `session_suppressed:session_neutral_attach_unsafe` solely because the residual window is unstable;
- an inconclusive probe timeout releases the candidate rather than blacklisting the session.

## 3. Bounded differential proof

After a neutral attach is accepted, SoundCeiling applies only the existing `-0.5 dB` test gain.

Pass:
- `session_dsp_probe_begin ... requestedGainDb=-0.5` appears;
- stable response near the requested shift becomes `LINEAR_SAFE` / verified;
- oversized stable response remains non-verified and fail-closed;
- unstable response is `INSUFFICIENT_EVIDENCE`, not `RESPONSIVE_NONLINEAR`.

## 4. Real normalization at 3/15

Once Session DSP is verified, continue playing material with quiet and loud passages.

Pass:
- `actuatorTier=SESSION_DSP` appears;
- `dspRequestedGainDb` and `dspAppliedGainDb` become non-zero when correction is needed;
- `session_dsp_apply` reports the same non-zero session;
- Samsung Media stays at the user-selected 3/15 during ordinary normalization;
- Safety Maximum / Quiet Now remain the only explicit Media safety controls.

## 5. Evidence bundle

- Export the full fresh SoundCeiling log from startup through at least one complete Session DSP probe.
- Record the tested APK SHA-256.
- Note whether the 0 dB attach caused any audible level change.
- If DSP verifies, note whether quiet passages audibly rise while Samsung remains at 3/15.
