# SoundCeiling v0.7.7.1 Samsung Session DSP checklist

Target: Samsung SM-A528B / Android 14. Keep the user's normal low-volume anchor; **3/15 is a required acceptance point**. The previously granted `android.permission.DUMP` should remain granted when installing this build as an update with the same package/signing identity.

## 1. Deterministic Enhanced Session verification

1. Start Yandex Music or YouTube with Smart PCM and Global DSP enabled.
2. Set Samsung Media to 3/15 and do not move it during verification.
3. Let playback run for at least 10 seconds.

Pass:
- an exact non-zero session is discovered with the expected UID/package;
- `session_dsp_readback_begin` appears for that session;
- the candidate uses input-gain-only topology: PreEQ/MBC/PostEQ/Limiter are all out of use;
- Android readback completes the bounded sequence `0 dB -> -0.5 dB -> 0 dB` on every configured channel;
- `session_dsp_readback_result ... verified=true` appears;
- `session_dsp_attached ... verified_readback` follows;
- Samsung Media remains 3/15.

Fail-closed:
- topology/readback mismatch produces `session_readback_unverified` and releases/suppresses that exact session;
- failed restore to 0 dB never promotes DSP authority;
- no unverified transport may receive ordinary positive normalization gain.

## 2. PCM/Visualizer residuals are diagnostic only

Dynamic music can make targeted PCM and Visualizer residuals differ because those meters are not audio-time synchronized.

Pass:
- noisy source/output residuals do not decide Enhanced Session authority;
- a large or positive residual by itself does not produce `session_neutral_attach_unsafe`;
- the production Enhanced Session path does not emit the old acoustic `session_dsp_attach_result` / `session_dsp_probe_result` gate sequence;
- ordinary metering and output-domain safety remain available for normalization decisions after the Session DSP transport is verified.

## 3. Real normalization at 3/15

Once Session DSP is verified, continue playing material with quiet and loud passages.

Pass:
- `actuatorTier=SESSION_DSP` appears;
- `dspRequestedGainDb` and `dspAppliedGainDb` become non-zero when correction is needed;
- `session_dsp_apply` reports the same non-zero session;
- quiet material can receive positive DSP gain without moving Samsung Media;
- Samsung Media stays at the user-selected 3/15 during ordinary normalization;
- Safety Maximum / Quiet Now remain the only explicit Media safety controls.

## 4. Session lifecycle

Pass:
- changing app/audio session releases the old verified transport before a new one is verified;
- changing route clears suppression and requires a fresh exact-session readback handshake;
- stopping/restarting SoundCeiling neutralizes the effect before release;
- an apply failure revokes Session DSP authority and returns ordinary normalization to HOLD rather than moving Media.

## 5. Evidence bundle

- Export the full fresh SoundCeiling log from startup through `session_dsp_readback_result` and several `session_dsp_apply` events.
- Record the tested APK SHA-256.
- Note whether verification caused any audible step; `-0.5 dB` should be only a tiny bounded transient.
- Note whether quiet passages audibly rise while Samsung remains at 3/15.
