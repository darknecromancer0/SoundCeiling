# SoundCeiling v0.7.7 Samsung field checklist

Target device: Samsung / One UI, 15-step Media stream.

## One-time Enhanced Session DSP setup

1. Install the v0.7.7 debug APK.
2. Connect the phone with USB debugging enabled and grant the one-time diagnostic permission:

   `adb shell pm grant dev.soundceiling.app android.permission.DUMP`

3. Re-open SoundCeiling. The setup warning and copy-command button must disappear after the permission is visible to the app.
4. Start playback in YouTube or Yandex Music, then start SoundCeiling.

Expected: discovery must select a **non-zero** audio session owned by the exact playback UID before DSP authority is granted. Session `0` is not an acceptable Enhanced Session DSP target.

## Critical 3/15 authority test

1. Set Samsung Media manually to **3/15**.
2. Keep Safety Maximum at 100% for this normalization check.
3. Play alternating quiet and loud material for at least 30 seconds.
4. Move Media manually 3/15 -> 2/15 -> 3/15 while playback continues.

Pass conditions:

- SoundCeiling never raises or lowers the Samsung Media step for ordinary Session DSP normalization.
- The user's manual 3/15, 2/15 and 3/15 choices remain authoritative.
- With a verified non-zero session, normal correction is reported as Session DSP / `DSP_GAIN` and gain changes independently of the Media step.
- Without a verified non-zero session, ordinary normalization is **HOLD**. It must not revive the old coarse Media fallback merely to chase target loudness.
- Hard Safety Maximum may still reduce Media only when its explicit safety condition is actually hit.

## Telemetry and logs

Capture a fresh SoundCeiling log and verify that the active Session DSP path exposes:

- session ID greater than zero;
- UID and package;
- requested DSP gain;
- applied DSP gain;
- reason such as `session_dsp_active`;
- `session_dsp_apply` entries when gain is commanded.

If applying gain to an already verified session fails, pass behavior is fail-closed: release that Session DSP authority and transition to HOLD rather than touching ordinary Media volume.

## Source switching / lifecycle

1. Switch between YouTube and Yandex Music during playback.
2. Pause playback, resume it, then stop and restart SoundCeiling.
3. Confirm a stale session is not reused after its owning playback endpoint disappears or changes.
4. Confirm Session DSP is released when SoundCeiling stops.

## Final evidence to save

- v0.7.7 APK used for the test;
- APK SHA-256;
- fresh SoundCeiling log covering the 3/15 test;
- whether the ADB permission was granted;
- observed non-zero session ID / package;
- any unexpected Samsung Media movement, including exact before/after steps and timestamp.
