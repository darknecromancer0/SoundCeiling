# SoundCeiling v0.7.6 Samsung acceptance checklist

Status: awaiting device test

Use the exact APK and SHA from the immutable v0.7.6 GitHub Actions head. Do not substitute another build between CI verification and the phone test.

## Physical acceptance cases

1. **Media 1/15 and 2/15** with Yandex Music and YouTube. Play material with mastered peaks near 0 dBFS. The Samsung Media slider must not move down merely because the raw/source peak is high. Look for `raw_peak_not_output_emergency` rather than a fast Media write when there is no output-domain emergency.
2. **Manual 1→2, 2→3, 3→2**. Each manual Samsung move must remain where placed with no millisecond snap-back. The current user-selected step must become the master anchor immediately.
3. If the log contains **`dsp_differential_probe_result verified=true`**, compare loud and quiet passages while Media remains fixed. Normalization should occur through DSP and the log should show changing **`dspAppliedGainDb`** values rather than Samsung slider chasing.
4. If DSP remains unverified, verify there is no fast slider motion. Any **Coarse Media fallback** write must be **one step** only, separated by **dwell**, and justified by sustained output imbalance rather than a single raw peak.
5. **Stop/restart at least 5 times**. Start normalization, stop it, then start again repeatedly. No crash, cache warning, stuck foreground service, stale DSP attenuation, or forced Media reset is acceptable.
6. **Export one complete log** containing startup, Global DSP differential probe, loud and quiet passages, manual Media moves, any coarse fallback decisions, and final stop.
