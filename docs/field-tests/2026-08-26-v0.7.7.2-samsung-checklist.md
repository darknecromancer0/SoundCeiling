# SoundCeiling v0.7.7.2 Samsung Session DSP checklist

Target: Samsung SM-A528B / Android 14. Media 3/15 remains a required acceptance point.

## 1. Session creation compatibility

1. Start Yandex Music or YouTube with Smart PCM and Global DSP enabled.
2. Set Samsung Media to 3/15.
3. Let playback run until the source becomes EXACT and a non-zero session is discovered.

Pass:
- `session_discovered` reports the exact UID/package;
- `session_dsp_readback_begin` appears;
- the DynamicsProcessing architecture is accepted by Samsung instead of failing with `dsp_create_failed:custom=IllegalArgumentException`;
- PreEQ, MBC and PostEQ are not in use;
- Limiter may exist only as the Samsung compatibility shell and must read back `limiter enabled=false` on every channel;
- input gain remains 0 dB before the bounded probe.

Fail closed:
- any enabled limiter rejects Session DSP authority;
- any topology/readback mismatch rejects the session;
- OEM default-config fallback remains disabled for Enhanced Session.

## 2. Deterministic readback

Pass:
- `session_dsp_readback_result ... verified=true` appears after `0 dB -> -0.5 dB -> 0 dB` input-gain readback on every channel;
- `session_dsp_attached ... verified_readback` follows;
- Samsung Media remains at the user-selected step throughout verification.

## 3. Real normalization at Media to 3/15

Continue playing quiet and loud material.

Pass:
- `actuatorTier=SESSION_DSP` appears;
- `session_dsp_apply` uses the discovered non-zero session;
- `dspAppliedGainDb` becomes non-zero when correction is needed;
- quiet material can receive positive DSP gain without moving Samsung Media from 3/15;
- loud material is constrained by the existing headroom/safety planner;
- Safety Maximum and Quiet Now remain the only explicit Media safety actuators.

## 4. Evidence bundle

- Export the full fresh SoundCeiling log from startup through readback and several DSP apply events.
- Record the tested APK SHA-256.
- Note any audible step during verification.
- Note whether quiet passages actually rise while Samsung remains at 3/15.
