# SoundCeiling v0.9.0 Samsung field checklist

Device focus: Samsung SM-A528B / Android 14. This is a safety and shadow-feasibility run. PCM DSP
must not change audible output in v0.9.0.

## Stop conditions

Stop SoundCeiling immediately and export the log if attaching/starting it makes Samsung Media sound
full-scale, locks the physical volume, distorts audio, duplicates/echoes playback, or reverses a
manual Volume Down action. Do not repeat a failed step with headphones or loud speakers.

## 1. Install-over and startup quarantine

- [ ] Install-over from v0.8.0 succeeds without clearing app data; Android reports v0.9.0.
- [ ] Before playing audio, Simple and Advanced show `Session DSP quarantined` and
      `field_quarantined_neutral_media_bypass`.
- [ ] The UI shows `PCM DSP: Shadow only · audible output blocked`; there is no DUMP/ADB setup
      button or permission request.
- [ ] Export the first startup log before touching Samsung Media.
- [ ] The log contains `session_dsp_quarantine` with `constructorAllowed=false`.
- [ ] The log contains no `session_dsp_candidate_attempt`, `session_dsp_candidate_selected`,
      `session_dsp_readback_begin`, `session_dsp_attached`, or `session_dsp_apply` event.

## 2. Samsung Media and Safety authority

- [ ] With quiet test audio, move Samsung Media slowly through 1/15, 2/15, 3/15, and 4/15.
      Each step remains the user's physical master; SoundCeiling does not jump to full scale or lock
      the slider.
- [ ] Drag Volume Down several steps while audio plays. The lower setting remains authoritative and
      is not automatically repaid as SoundCeiling debt.
- [ ] Set the automatic/output target above Safety Maximum. Samsung Media never remains above
      Safety Maximum; illegal panel overshoots do not become the anchor or debt.
- [ ] Hold Samsung panel Volume Up against the cap for three seconds. Record any first transient or
      repeated SystemUI rewrite; do not interpret reactive clamp as pre-write interception.
- [ ] Quiet Now only lowers/holds. Stop does not restore an older Media value.

## 3. PCM feasibility and shadow direction

- [ ] Play Yandex Music or YouTube until targeted PCM and exact source confidence are established.
- [ ] The log contains `pcm_dsp_feasibility` with `mode=SHADOW_ONLY`,
      `captureSemantics=COPY_ONLY`, `duplicatePrevention=UNAVAILABLE`,
      `audibleOutputAllowed=false`, and `public_playback_capture_keeps_original_audio`.
- [ ] There is no echo, doubled playback, or other audible shadow output. Changing shadow gain in
      telemetry does not move Samsung Media and must not be described as speaker-applied gain.
- [ ] A sustained quiet passage produces an eligible `pcm_dsp_shadow` event with positive
      `shadowGainDb`.
- [ ] A sustained loud passage produces an eligible `pcm_dsp_shadow` event with lower/negative
      `shadowGainDb`.
- [ ] A high source peak is immediately bounded: `projectedOutputPeakDbfs` does not exceed the
      configured hard peak ceiling and `shadowPcmPeakDbfs` stays at or below -0.5 dBFS.
- [ ] Every eligible shadow event reports `clippedSamples=0`.
- [ ] An OFF/excluded app, mixed/unknown source, or unknown capture reference reports inactive
      shadow processing and never receives positive shadow gain.

## 4. Lifecycle regressions

- [ ] Change between speaker and another safe output route. Shadow state returns to neutral before
      collecting new route evidence; Session DSP remains quarantined.
- [ ] Stop and restart twice. Samsung Media is not restored or raised, and shadow state starts from
      0 dB each time.
- [ ] Let targeted capture rebind to mixed and back. Each capture lifecycle emits one
      `pcm_dsp_feasibility` event and remains non-audible.
- [ ] Export the complete log and note the Samsung Media step, Safety Maximum, source/app, route,
      and approximate wall-clock time of every anomaly.

## Expected result

v0.9.0 passes only if the v0.8 physical Media bypass is gone, Safety/Volume Down remain authoritative,
no Session constructor path is observed, and PCM shadow telemetry proves both gain directions and
peak safety without audible replay. Audible loudness normalization is not an acceptance claim for
this build.
