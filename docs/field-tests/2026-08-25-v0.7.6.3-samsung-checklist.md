# SoundCeiling v0.7.6.3 Samsung field checklist

Target device: Samsung SM-A528B / Android 14. Prefer the same speaker and Bluetooth routes used for the v0.7.6.x field logs.

## Test setup

For this diagnostic run only, set **Safety Maximum to 100%** so the explicit hard Media cap does not stop a 3/15 -> higher-step test. This does not disable the independent output ceilings or change the product default. Restore the desired Safety Maximum after testing.

Use Smart PCM, Global DSP ON, Default Linked Lock ON, and stable music in Yandex Music or YouTube. Grant source recognition / playback capture when requested.

## 1. Neutral attach evidence must not fail early

Start playback and leave Samsung Media unchanged while the Global DSP probe begins.

Pass:
- `dsp_global_attach_begin` occurs only after baseline evidence;
- attach timing starts after the neutral transport has actually been enabled;
- if valid neutral-attach coverage is still below 250 ms, log may show `dsp_global_attach_wait` with `attach_insufficient_coverage` or `attach_insufficient_pairs`;
- a retryable wait must NOT immediately emit `dsp_global_attach_unsafe` or `dsp_global_probe_suppressed`;
- `coveredMs` is visible in `dsp_global_attach_result` diagnostics.

## 2. Conclusive attach result

Continue stable playback without moving Samsung Media.

One of these outcomes is acceptable:

A. Neutral attach is proven safe:
- `dsp_global_attach_result safe=true retryable=false`;
- `deltaDb` is finite and within the neutral tolerance;
- the bounded `requestedGainDb=-0.5` differential probe begins afterward.

B. Neutral attach is proven non-neutral:
- `dsp_global_attach_result safe=false retryable=false` with finite `deltaDb`;
- `dsp_global_attach_unsafe` appears;
- transport is detached and route suppression remains active.

C. Evidence never becomes sufficient:
- the transport remains neutral while evidence is retryable;
- the existing bounded probe timeout eventually cancels/rejects it;
- it is never promoted to verified DSP without proof.

`deltaDb=NaN` from insufficient coverage by itself must not be labeled as a proven unsafe non-neutral attach.

## 3. Verified DSP path, if Samsung accepts it

If the neutral attach succeeds, keep playback stable through the -0.5 dB probe.

Pass for verified continuous DSP:
- differential result is `verified=true` / linear-safe with a measurable response close to the requested bounded probe;
- runtime reports verified Global DSP rather than Coarse Media fallback;
- subsequent control can produce non-zero `dspAppliedGainDb` when requested gain is non-zero;
- Samsung Media remains the user master anchor and does not get walked down merely to simulate DSP.

If the probe is responsive but nonlinear, no continuous DSP authority is granted.

## 4. Output-domain regression guard

Wait until targeted PCM establishes `captureRef=PRE_VOLUME`.

Pass:
- `meterDomain=PROJECTED`;
- projected output includes `mediaRouteGainDb`;
- Visualizer-only UNKNOWN evidence cannot authorize ordinary Media normalization;
- there is no gradual Visualizer-driven 9->8->7 sink.

## 5. User authority and Safety Maximum

With Safety Maximum temporarily at 100%, manually test 3->4, 4->6, 6->4 and one lower-volume move.

Pass:
- SoundCeiling does not snap the slider back just because the user moved it;
- user movement rebases the anchor;
- ordinary recovery does not exceed the latest user anchor;
- only an actually configured Safety Maximum / hard safety rule may impose a hard Media cap.

## 6. Evidence package

- Stop/restart at least 5 times.
- Export one complete log containing startup, attach, differential probe, capture-reference and CONTROL lines.
- Record the tested APK SHA-256.
- Note route (phone speaker / exact Bluetooth device) and Samsung Media step used during the attach probe.
