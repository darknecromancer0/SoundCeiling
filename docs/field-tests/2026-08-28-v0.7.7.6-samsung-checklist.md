# SoundCeiling v0.7.7.6 Samsung Strict Safety field checklist

Device target: Samsung SM-A528B / Android 14.

## Setup

1. Install the stable-signed v0.7.7.6 APK over v0.7.7.5.
2. Open Simple or Advanced mode and tap `Включить Strict Safety (Accessibility)`.
3. In Android Accessibility settings enable `SoundCeiling Strict Safety`.
4. Start SoundCeiling and set Safety Maximum so the effective hard ceiling is 4/15.
5. Start Yandex Music and wait for exact-source/targeted PCM detection.

## Safety acceptance

- From 3/15, press Volume-Up once: 4/15 is allowed.
- At 4/15, hold hardware Volume-Up for at least 5 seconds. Media must remain <=4/15.
- Repeatedly drag the Samsung volume panel above 4. The reactive latch must force Media back to <=4 and the log must not persist 5/7/11/15 as `mediaAnchor`.
- Exercise Volume-Down through `4 -> 3 -> 2 -> 1 -> 0`. Volume-Down must always pass through and SoundCeiling must not raise Media back in response.
- Stop SoundCeiling. Normal hardware Volume-Up behavior must immediately return.

## Log acceptance

Expected evidence includes `strict_safety_volume_up`, `hard_cap_latch_enter`, `hard_cap_latch_write` and eventually `hard_cap_latch_release` when slider overshoot is exercised.

Reject the build if the log contains any persistent RED `safety_cap_violation`, if an illegal overshoot becomes the user Media anchor/Linked Lock basis, if a user Volume-Down is reversed, or if control remains active after service stop.
