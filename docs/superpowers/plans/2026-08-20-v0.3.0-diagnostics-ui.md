# SoundCeiling v0.3.0 Diagnostics and Dual-Mode UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Выпустить SoundCeiling v0.3.0, который не устанавливает Media в mute при обнаруженном сигнале, пишет локальную трассировку решений и предоставляет простой, расширенный и калибровочный экраны.

**Architecture:** Управляющая математика переносится в чистые Java-компоненты с детерминированной кривой и последней защитой слышимого минимума; Android-сервис только захватывает PCM, применяет готовое решение и публикует единый снимок состояния. Диагностика, частотный индикатор, тест-тоны и программно построенный UI подключаются поверх того же `RuntimeState`, поэтому все экраны показывают одно и то же решение контроллера.

**Tech Stack:** Android API 29–35, Java 17, программный Android View UI, AudioPlaybackCapture, AudioTrack, MediaStore Downloads, чистые Java-тесты через `javac`, Gradle, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-08-20-v0.3.0-diagnostics-ui-design.md`

## Global Constraints

- `versionCode = 5`, `versionName = 0.3.0`.
- Package: `dev.soundceiling.app`.
- `minSdk = 29`, `targetSdk = 35`, `compileSdk = 35`, Java 17.
- Новые внешние runtime-зависимости не добавляются.

```java
final class ControlVolumeCurve {
    private static final float MUTED_GAIN_DB = -80f;
    private static final float LOOKUP_TOLERANCE_DB = 0.20f;
    private final int minIndex;
    private final int maxIndex;
    private final float[] gains;

    ControlVolumeCurve(int minIndex, int maxIndex) {
        if (maxIndex <= minIndex) throw new IllegalArgumentException("degenerate volume range");
        this.minIndex = minIndex;
        this.maxIndex = maxIndex;
        gains = new float[maxIndex - minIndex + 1];
        gains[0] = MUTED_GAIN_DB;
        for (int offset = 1; offset < gains.length; offset++) {
            float normalized = offset / (float) (gains.length - 1);
            gains[offset] = (float) (20.0 * Math.log10(normalized));
        }
    }

    int minIndex() { return minIndex; }
    int maxIndex() { return maxIndex; }
    float gainDbForIndex(int index) {
        return gains[DbMath.clamp(index, minIndex, maxIndex) - minIndex];
    }
    int capIndexFromPercent(int percent) {
        float normalized = DbMath.clamp(percent, 0, 100) / 100f;
        return DbMath.clamp(Math.round(minIndex + normalized * (maxIndex - minIndex)),
                minIndex, maxIndex);
    }
    int bestIndexAtOrBelowGain(float desiredGainDb, int capIndex) {
        int cap = DbMath.clamp(capIndex, minIndex, maxIndex);
        int best = minIndex;
        float bestError = Float.MAX_VALUE;
        for (int index = minIndex; index <= cap; index++) {
            float gain = gainDbForIndex(index);
            if (gain <= desiredGainDb + LOOKUP_TOLERANCE_DB) {
                float error = Math.abs(desiredGainDb - gain);
                if (error < bestError) { best = index; bestError = error; }
            }
        }
        return best;
    }
    float[] snapshot() { return gains.clone(); }
}
```

```java
static Plan splFromEstimate(
        float sourceRmsDb, float sourcePeakDb,
        float currentControlGainDb, float currentMeasurementGainDb,
        float calibrationOffsetDb, float targetSpl, float peakCeilingSpl,
        boolean normalize, float strength) {
    float estimatedRmsSpl = sourceRmsDb + currentMeasurementGainDb + calibrationOffsetDb;
    float estimatedPeakSpl = sourcePeakDb + currentMeasurementGainDb + calibrationOffsetDb;
    float idealControlGain = currentControlGainDb + targetSpl - estimatedRmsSpl;
    float peakControlLimit = currentControlGainDb + peakCeilingSpl - estimatedPeakSpl;
    float targetControlled = normalize
            ? currentControlGainDb + DbMath.clamp(strength, 0f, 1f)
                    * (idealControlGain - currentControlGainDb)
            : currentControlGainDb;
    return new Plan(idealControlGain, peakControlLimit,
            Math.min(targetControlled, peakControlLimit), estimatedPeakSpl, peakCeilingSpl);
}
```

static short[] sinePcm16(int sampleRate, int durationMs, float frequencyHz,
        float peakDbfs, int channels) {
    if (sampleRate <= 0 || durationMs <= 0 || frequencyHz <= 0f || channels <= 0) {
        throw new IllegalArgumentException("positive tone parameters required");
    }
    int frames = Math.multiplyExact(sampleRate, durationMs) / 1000;
    short[] pcm = new short[Math.multiplyExact(frames, channels)];
    double scale = 32767.0 * Math.pow(10.0, peakDbfs / 20.0);
    for (int frame = 0; frame < frames; frame++) {

                * scale);
        short sample = (short) DbMath.clamp(value, Short.MIN_VALUE, Short.MAX_VALUE);

        }
    }

- [ ] **Step 4: Implement Goertzel levels with smoothing**

For every PCM frame, average channels and use this calculation; the class stores only `levels`, never the input array:

```java
private static final float[] CENTERS = {80f, 250f, 1000f, 4000f, 10000f};

float[] update(short[] pcm, int sampleCount) {
    int count = DbMath.clamp(sampleCount, 0, pcm.length);
    int frames = count / channelCount;
    if (frames < 2) return levels();
    for (int band = 0; band < CENTERS.length; band++) {
        double coefficient = 2.0 * Math.cos(2.0 * Math.PI * CENTERS[band] / sampleRate);
        double previous = 0.0;
        double previous2 = 0.0;
        for (int frame = 0; frame < frames; frame++) {
            double mono = 0.0;
            for (int channel = 0; channel < channelCount; channel++) {
                mono += pcm[frame * channelCount + channel] / 32768.0;
            }
            mono /= channelCount;
            double window = 0.5 - 0.5 * Math.cos(2.0 * Math.PI * frame / (frames - 1));
            double current = mono * window + coefficient * previous - previous2;
            previous2 = previous;
            previous = current;
        }
        double power = previous * previous + previous2 * previous2
                - coefficient * previous * previous2;
        double amplitude = 2.0 * Math.sqrt(Math.max(0.0, power)) / frames;
        float dbfs = (float) (20.0 * Math.log10(Math.max(0.0001, amplitude)));
        float normalized = DbMath.clamp((dbfs + 80f) / 80f, 0f, 1f);
        levels[band] = levels[band] * 0.65f + normalized * 0.35f;
    }
    return levels();
}
```
