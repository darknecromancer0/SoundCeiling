# SoundCeiling v0.7 Adaptive Envelope Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship SoundCeiling v0.7.0 with user-authoritative adaptive-envelope normalization, recoverable automatic attenuation, safer transient handling, truthful source/DSP status, repaired Logs UX, readable light/dark visualizers, and a live EQ spectrum/curve with global EQ Amount.

**Architecture:** Keep Samsung `STREAM_MUSIC` as the actuator, but split user intent from SoundCeiling-owned attenuation. A new pure `AdaptiveVolumeEnvelope` determines how far automatic recovery may go; `LoudnessControlPolicy` becomes bidirectional only inside that envelope, while hard safety remains final. Independent source/DSP/Logs/UI improvements are implemented behind their current adapters and do not weaken the safety path.

**Tech Stack:** Android Java, AudioManager/AudioPlaybackCapture/MediaProjection, MediaSessionManager + NotificationListenerService, Android Equalizer/Visualizer APIs where available, SharedPreferences, MediaStore/SAF, pure Java regression tests, shell source-contract tests, GitHub Actions/Gradle.

**Spec:** `docs/superpowers/specs/2026-08-22-v0.7-adaptive-envelope-design.md`

## Global Constraints

- Base branch is SoundCeiling v0.6.0 `main` at `e9c6f75333f133bc4fdf82d9cb95c4e3f3b91942`.
- Manual Samsung Media DOWN immediately lowers automatic authority; SoundCeiling may never automatically exceed that user ceiling until the user raises Media again.
- Automatic UP is recovery of SoundCeiling-owned attenuation only, never unrestricted boosting.
- Configured Maximum and Safety Lock remain absolute ceilings.
- A user may manually move below configured Minimum; Minimum constrains automatic DOWN only and never authorizes automatic UP.
- `MIXED/UNKNOWN` source identity may recover only attenuation whose provenance is known to be SoundCeiling-owned in the same runtime/route epoch.
- Production analysis must never use microphone/call/voice audio sources.
- DSP/source labels must remain evidence-based; constructing an Equalizer or capturing PCM does not prove verified DSP transport.
- Stock Android cannot physically shrink Samsung's volume-slider range; hard-cap behavior remains fast reactive clamp-back.
- No root/Shizuku requirement is introduced in Standard v0.7.

- [ ] **Step 1: Implement minimal state accounting**

Create `AdaptiveVolumeEnvelope.java`:

```java
package dev.soundceiling.app;

final class AdaptiveVolumeEnvelope {
    private int userCeilingIndex;
    private int automaticReferenceIndex;
    private int lastObservedIndex;
    private float manualOffsetDb;
    private boolean initialized;

    void observeInitial(int currentIndex, int safetyCeilingIndex, long nowMs) {
        int current = Math.max(0, currentIndex);
        userCeilingIndex = Math.min(current, Math.max(0, safetyCeilingIndex));
        automaticReferenceIndex = userCeilingIndex;
        lastObservedIndex = current;
        manualOffsetDb = 0f;
        initialized = true;
    }

    void onUserChange(int previousIndex, int currentIndex, ControlVolumeCurve curve, long nowMs) {
        ensure(currentIndex, Math.max(previousIndex, currentIndex), nowMs);
        if (currentIndex < previousIndex) {
            userCeilingIndex = Math.min(userCeilingIndex, currentIndex);
            automaticReferenceIndex = Math.min(automaticReferenceIndex, userCeilingIndex);
            float delta = curve.gainDbForIndex(currentIndex) - curve.gainDbForIndex(previousIndex);
            if (Float.isFinite(delta) && delta < 0f) manualOffsetDb += delta;
        } else if (currentIndex > previousIndex) {
            userCeilingIndex = Math.max(userCeilingIndex, currentIndex);
            automaticReferenceIndex = Math.max(automaticReferenceIndex, currentIndex);
        }
        lastObservedIndex = currentIndex;
    }

    void onAppWriteAck(VolumeWriteTracker.WriteOrigin origin, int previousIndex, int appliedIndex,
                       ControlVolumeCurve curve, long nowMs) {
        ensure(previousIndex, Math.max(previousIndex, appliedIndex), nowMs);
        if (origin == VolumeWriteTracker.WriteOrigin.NORMALIZER_DOWN
                || origin == VolumeWriteTracker.WriteOrigin.PEAK_EMERGENCY
                || origin == VolumeWriteTracker.WriteOrigin.TRANSIENT_EMERGENCY) {
            automaticReferenceIndex = Math.max(automaticReferenceIndex, previousIndex);
        }
        lastObservedIndex = appliedIndex;
    }

    int userCeilingIndex() { return userCeilingIndex; }
    int recoverableCeilingIndex(int safetyCeilingIndex) {
        return Math.min(Math.min(userCeilingIndex, automaticReferenceIndex), Math.max(0, safetyCeilingIndex));
    }
    float manualOffsetDb() { return Math.min(0f, manualOffsetDb); }
    boolean hasRecoverableAttenuation(int currentIndex) { return currentIndex < automaticReferenceIndex && currentIndex < userCeilingIndex; }
    void onRouteEpochReset(int currentIndex, int safetyCeilingIndex, long nowMs) { observeInitial(currentIndex, safetyCeilingIndex, nowMs); }

    private void ensure(int current, int safety, long nowMs) {
        if (!initialized) observeInitial(current, safety, nowMs);
    }
}
```
