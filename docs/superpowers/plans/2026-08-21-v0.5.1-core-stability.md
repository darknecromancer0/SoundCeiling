> Implement against `feature/v0.5.1-core-stability` using red/green regression tests and full Android CI.

## Task 1: Reproduce and lock down control-loop failures

Files: `tests/PureLogicTest.java`, `tests/HybridPolicyPureTest.java`, `tests/HybridCoordinatorPureTest.java`.

Add failing tests for:
- transient event re-arms instead of latching;
- projected-output peak is already safe at low Media index;
- initial Minimum does not imply manual pause;
- healthy ACTIVE PCM_MIXED with no exact source can use Global normalization;
- explicit OFF/candidate conflict still blocks source-specific control;
- Quiet Now target is downward-only;
- target loudness changes produce different requested targets.

Run CI and confirm RED for the intended missing behaviors.

Run pure tests until GREEN.
