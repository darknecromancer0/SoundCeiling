# SoundCeiling v0.7.6 Control Architecture Reset Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Restore the original SoundCeiling contract: Samsung Media is the user master anchor; verified DSP performs continuous loudness normalization/peak limiting; unverified-DSP fallback is slow, one-step Media trim based on sustained output-domain evidence.

**Architecture:** Separate measurement domains from actuator ownership. `OutputLevelModel` owns SOURCE / direct OUTPUT / PROJECTED math. `DspDifferentialVerifier` proves session-zero DSP by paired PlaybackCapture + Visualizer residuals. `ContinuousDspController` owns smooth verified-DSP gain. `CoarseMediaFallbackController` owns slow fallback. `NormalizerControlCoordinator` is the single actuator-tier arbiter; `NormalizerService` becomes Android evidence/wiring only.

**Tech Stack:** Android 10+ (`minSdk=29`, `targetSdk=35`, `compileSdk=35`), Java 17, AudioPlaybackCapture, `Visualizer(0)` with `SCALING_MODE_AS_PLAYED` and `MEASUREMENT_MODE_PEAK_RMS`, `DynamicsProcessing`, pure Java tests, GitHub Actions `assembleDebug`.

**Spec:** `docs/superpowers/specs/2026-08-24-v0.7.6-control-architecture-reset-design.md`

## Global Constraints

- Raw/source peak cannot directly trigger Media emergency for PRE_VOLUME or UNKNOWN capture.
- PRE_VOLUME projected output includes Samsung route gain; POST_VOLUME does not double-apply it.
- Fresh Visualizer output-mix peak/RMS is direct OUTPUT-domain evidence and has priority over PRE/POST inference.
- UNKNOWN without direct output evidence stays fail-closed; raw PCM is never substituted as output peak.
- Verified DSP is the continuous actuator. Preference ON is not capability proof.
- Coarse Media fallback moves at most one step per decision and only after sustained imbalance/dwell.
- MEDIUM coarse dwell starts at 1000 ms, LIGHT 1500 ms, STRICT 800 ms.
- Manual Media change immediately rebases the user anchor and cancels pending coarse recovery.
- Hard Media maximum, Quiet Now, Auto mute floor, app/system OFF, Linked Lock provenance, and v0.7.4.1/v0.7.4.2 teardown fixes remain intact.
