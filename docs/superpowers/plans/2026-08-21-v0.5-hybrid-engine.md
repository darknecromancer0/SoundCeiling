# SoundCeiling v0.5 Hybrid Engine Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship SoundCeiling v0.5 with a capability-driven Standard Engine that preserves the tested v0.4 safety core while adding trustworthy PCM/fallback state, per-app policies, system-stream ceilings, Device Profiles 2.0, conservative multi-source conflict handling, and truthful DSP/per-app capability reporting.

**Architecture:** Refactor `NormalizerService` into a thin lifecycle/orchestration shell around pure capability, source, policy, and state resolvers plus Android adapters. Reuse v0.4 `SafetyGuard`, `SafeVolumeController`, manual override, loudness, peak/transient and diagnostics logic instead of rewriting them. Automatic upward control is allowed only when source identity and metering confidence satisfy the v0.5 spec; otherwise the engine is downward-only or hold-only.

**Tech Stack:** Android Java, `AudioManager`, `AudioPlaybackCallback`, `AudioPlaybackCaptureConfiguration`, MediaProjection, PackageManager, SharedPreferences/JSON, existing pure Java regression harness, GitHub Actions, Gradle `assembleDebug`.

**Spec:** `docs/superpowers/specs/2026-08-21-v0.5-hybrid-engine-design.md`

## Global Constraints

- Android 10+ remains supported.
- Standard Engine requires no root/Shizuku/OEM privilege.
- No confidence, no raise: `LIKELY`, `MIXED`, `UNKNOWN`, `BLOCKED`, `UNCERTAIN`, `ERROR`, or unhealthy metering must disable automatic upward control.
- Global Safety Lock remains final and cannot be weakened by app/device settings.
- All Samsung/system apps default app-policy `OFF`; ordinary third-party user apps default `GLOBAL`.
- Media system policy defaults `ON`; Calls/Alarm/Ringtone/Notifications/other non-Media streams default `OFF`.
- Production analysis must not use physical microphone, call, or voice audio sources.
- Package name is persistence identity; UID is runtime metadata and must be refreshed.
- PCM capture is analysis only and must not be reported as DSP transport.
- Unverified per-app/DSP/OEM capabilities must report unavailable/degraded, never simulated success.
- Existing v0.4 manual pause, SafetyGuard, LUFS-like, peak/transient, bounded logs and calibration data remain preserved.

## File Structure

### Pure engine model
- `EngineCapabilities.java` — immutable capability snapshot.
- `PlaybackSnapshot.java` — playback activity observation without unsupported identity claims.
- `SourceDescriptor.java` / `SourceSet.java` — package/UID metadata and identity confidence.
- `PcmAvailabilityState.java` / `PcmStateResolver.java` — blocked/silent/uncertain state machine.
- `AppRule.java` / `AppPolicy.java` — Global/On/Off/Custom persistence model.
- `SystemStreamPolicy.java` — separate stream enable/ceiling model.
- `EffectivePolicy.java` / `PolicyResolver.java` — global + device + app + stream conflict resolution.
- `CapabilityResolver.java` — independent metering/control/DSP capability resolution.
- `MultiSourceResolver.java` — deterministic conservative conflict behavior.

### Android adapters
- `PlaybackObserver.java` — `AudioPlaybackCallback` lifecycle and public playback metadata.
- `PackageSourceRepository.java` — package discovery, classification, UID resolution and app-policy storage.
- `AppClassifier.java` — one versioned source of Samsung/system defaults.
- `PcmCaptureBackend.java` — MediaProjection playback capture and optional UID filtering.
- `SystemStreamController.java` — explicitly enabled non-Media stream caps.
- `PerAppVolumeController.java` + `UnsupportedPerAppVolumeController.java` — truthful capability interface.
- `DspTransport.java` + `UnsupportedDspTransport.java` — truthful future-transport interface.
- `DeviceProfileV2.java` / `DeviceProfileV2Store.java` / `DeviceProfileMigrator.java` — route-specific safety data.

### Orchestration/UI
- `HybridEngineCoordinator.java` — pure-ish coordinator state around adapters, no direct AudioManager writes.
- `NormalizerService.java` — lifecycle shell delegating to coordinator/adapters.
- `AppsSystemView.java` — app search/rules and system sound controls.
- `DeviceProfilesView.java` — route profile summary/editing.
- `RuntimeState.java` / `DiagnosticsView.java` / `AdvancedModeView.java` / `SimpleModeView.java` — v0.5 status/capability rendering.
