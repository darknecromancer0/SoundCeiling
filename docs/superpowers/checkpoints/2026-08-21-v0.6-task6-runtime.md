# SoundCeiling v0.6 Task 6 runtime checkpoint

This checkpoint records the one-way runtime wiring before the Android build gate.

- Runtime control no longer defines a `RAISING` state.
- `UnexpectedZeroPolicy` attributes zero conservatively from `VolumeWriteTracker` mismatch evidence instead of a bare index transition.
- `RuntimeStateStore` trusts explicit zero provenance and preserves live meter age.
- Runtime telemetry carries configured/effective Target and Peak thresholds, manual threshold offset, controller action/reason, normal reaction latency and emergency latency.
- `NormalizerService` publishes the telemetry from the resolved policy and manual threshold follower.
- Detailed high-frequency logs are emitted for real downward writes; transient HOLD diagnostics are transition-gated.
- Local pure logic tests and `check-source-invariants.sh` pass on the exact patch content.

The remaining checkpoint is the GitHub Actions Android compile/build on this feature branch.
